# Sensors and Components Archive

An interactive 3D guide to the hardware, input and software touchpoints of smartphones and wearables. Built as a teaching aid: every entry has a short definition and a task to try on your own device.

Live site: https://cassaphim.github.io/Sensors-and-Components-Archive/

## What is in it

- **Hardware**: exploded 3D models of a phone, smartwatch, smart ring, smart glasses and an earbud, with clickable parts and sensors.
- **Input**: touch gestures, shown as animations on the phone's screen, plus voice, camera, motion and assistive input.
- **Software**: system surfaces, system sheets, UI components, foundations and states, drawn as simplified mockups with iOS and Android names.
- **Index**: all 282 entries by category, with approximate search that tolerates typos.

## Running it

The site is one file, `index.html`. Open it in a browser. It loads three.js and its fonts from public CDNs, so the 3D models need an internet connection.

## Notes

- The 3D models are schematic and do not depict a specific product.
- Platform terms and sensor descriptions were written from general knowledge and have not been checked against current OS releases.
